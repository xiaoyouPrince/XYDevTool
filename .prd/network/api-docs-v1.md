# 网络工具接口文档生成 — PRD v1

> **状态**：v1 已实现  
> **模块**：Network / API Docs  
> **最后更新**：2026-11-17  

---

## 1. 目标

基于本地请求历史中的真实样本，自动生成可读的接口说明（字段类型 + 示例），支持预览与导出 Markdown。  
**不**做成 ApiFox 级在线文档平台；字段业务说明后续再补人工编辑。

## 2. 范围（v1 / 方案 A）

| 包含 | 不包含 |
|------|--------|
| 从历史树（全部或指定分组）生成文档 | 字段中文说明编辑与回写 |
| 推断 JSON 类型并写成行内 `//` 注释 | OpenAPI / HTML 站点发布 |
| 请求 Query / Body / Header、响应样本 | AI 自动写中文业务说明 |
| 后台手写版式（uri / Method / 请求参数 / 响应） | 必填、枚举、错误码的自动推断 |
| 渲染预览 + Markdown 源码切换 + 导出 | |

## 3. 数据来源

- `HistoryNode`：name、分组路径、method、url、header、body、response  
- 响应先剥离 `_statusCode` / `_headers` / `_mimeType` 等调试字段（复用 Mock 组装逻辑）再推断与展示  

## 4. 交互

1. 网络工具底栏 **文档** 打开面板  
2. 选择范围：全部历史 / 当前选中分组（若选中为分组）  
3. 默认渲染预览（标题 / uri / Method / 带类型注释 JSON）；可切 Markdown 源码  
4. 复制 / 导出 `.md`  

## 5. 验收

1. 有 JSON body 的接口按手写风格输出，字段旁有类型注释  
2. 响应示例不含调试 meta 键  
3. 可导出 UTF-8 Markdown 文件  
4. 空历史时有明确提示  
5. 预览区默认渲染文档；枚举/错误码有人工补充占位
