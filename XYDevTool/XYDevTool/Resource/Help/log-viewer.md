# 运行日志

查看 XYDevTool 本机运行日志，便于排查功能使用路径与网络请求过程。日志仅保存在本机，请求相关内容会经过安全过滤。

## 打开方式

菜单栏 **Help**：

- **运行日志…** — 打开日志查看窗口
- **在 Finder 中显示日志** — 打开日志文件所在目录

## 界面说明

- **摘要栏**：事件数、会话数、失败数、平均耗时
- **筛选**：按模块、级别过滤；支持搜索事件名或运行数据
- **列表 / 详情**：左侧事件列表，右侧查看单条详情与元数据
- **刷新 / 清除**：重新加载或清空全部运行日志

## 常见模块

| 模块 | 含义 |
|------|------|
| 使用路径 | 主界面打开了哪些功能 |
| 网络请求 | 网络工具请求生命周期 |
| JSON 格式化 / JSON 转 Model / AppIcon 等 | 对应功能的关键操作 |
| 版本检查 | 启动时检查更新 |

## 说明

- 详情面板对过长字段仅预览前若干字符；完整内容请到日志目录中的文件查看
- 清除日志会删除本地已保存的运行日志，操作不可恢复
