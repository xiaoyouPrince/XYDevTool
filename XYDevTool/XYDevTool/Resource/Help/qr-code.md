# QRCode

本地二维码生成与识别工具。内容在本机处理，不依赖账号或云端服务。

## 打开方式

主界面点击 **QRCode**，打开独立窗口。

## 内容类型

左侧选择类型，中间填写表单，右侧实时预览：

| 类型 | 说明 |
|------|------|
| Text | 任意纯文本 |
| URL | 网页链接 |
| WiFi | SSID、密码、加密方式、是否隐藏网络 |
| Email | 收件人、主题、正文（`mailto:`） |
| SMS | 手机号与短信内容 |
| Phone | 电话号码（`tel:`） |
| vCard | 联系人信息（姓名、公司、职位、电话、邮箱、地址、网站） |
| App Link | App Scheme、Universal Link、App Store URL |
| Event | 日历事件（标题、地点、起止时间，可全天） |

## 基础参数

- **容错级别**：L / M / Q / H（默认 M）
- **静区边距**：二维码周围留白模块数
- **导出尺寸**：256 / 512 / 1024

## 结果操作

- **复制图片**：二维码 PNG 写入剪贴板
- **复制内容**：复制当前编码的原始字符串，便于核对
- **导出 PNG**：按所选尺寸保存到本地
- **识别图片**：导入含二维码的图片，解析并展示内容

## 说明

- 当前仅导出 PNG；样式颜色、Logo、SVG、历史记录、批量生成尚未提供
- 默认高对比度黑白码，优先保证可扫性
